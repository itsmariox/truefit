# Truefit 0.0.1 (pre-release) — DRAFT release notes

> Draft. Version number and tag `v0.0.1` are [OWNER TO CONFIRM]. Nothing here has been published.

Truefit is a Mac app that helps you tailor your CV to a job ad. You give it confirmed facts about your career, and it writes the CV from those facts. It is open source (MIT licence) and runs on your Mac.

**This is a pre-release.** It is the first public build, and rough edges are expected.

## Read this before you open it: the app is not signed by Apple

The DMG (`Truefit-0.0.1-unsigned.dmg`) is **unsigned and not notarised by Apple**. macOS will block the app the first time you open it. That is expected, and you approve it once:

1. Drag **Truefit** into your **Applications** folder.
2. Double-click it. When macOS warns you, click **Done** (do not move it to the Bin).
3. Open **System Settings → Privacy & Security**. Scroll down to the message about Truefit and click **Open Anyway**.
4. Enter your Mac password if asked, then click **Open** in the next box.

If macOS says the app is "damaged", open **Terminal** and run:

```
xattr -dr com.apple.quarantine /Applications/Truefit.app
```

then try again. The full steps are in [docs/FIRST-RUN.md](../FIRST-RUN.md).

What you can check, instead of a signature from Apple: the code is open for anyone to read, and this release has a published SHA-256 checksum (below). Only download Truefit from the official releases page of this repository.

## Requirements

- A Mac with Apple silicon.
- macOS: [OWNER TO CONFIRM: minimum macOS version]. (The app bundle's `LSMinimumSystemVersion` is 13.0, but it has not been tested on that version.)
- A Claude account (sign in with your Claude subscription, or paste an Anthropic API key), or an OpenAI account (paste an API key, or use your ChatGPT plan).

## Known limitations

- **Apple silicon only.** There is no Intel build.
- **Unsigned.** macOS warns on first launch, as described above.
- **Using a ChatGPT plan is a beta preview** that OpenAI may change or stop. A Claude subscription, an Anthropic API key and an OpenAI API key are the other ways to connect.
- Telegram is optional and off unless you turn it on.
- Pre-release: expect bugs.

## Privacy

There is no telemetry: no analytics, no crash reports. Your data stays on your Mac, except what the AI service you choose needs to do the work, Telegram messages if you turn Telegram on, and a job link you paste, which the app reads once. See the [README](../../README.md).
